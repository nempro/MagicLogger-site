# 魔道書 公式サイト

魔道書（MagicLogger）は、ChatGPTの会話ExportをWindows PCへ取り込み、手元で原文を閲覧・検索する無料のオープンソースアプリです。このリポジトリは公式サイトの静的ファイルを収録します。OpenAI / ChatGPTの公式製品ではありません。

サイトは`index.html`から開けます。GitHub Pagesでは`main`ブランチのルートを公開元にします。外部APIやバックエンドは不要です。サイト内の探索デモは架空の会話4件を使う体験表現で、関連記録のリンクはCoreの自動推薦機能ではありません。

CoreのソースとWindows版は別の`MagicLogger`リポジトリに掲載します。動作環境、取り込み制限、MIT Licenseの対象はサイトの「入手する」画面をご確認ください。サイト内のキャラクター・画像素材にCoreのMIT Licenseを適用するものではありません。

トップイラストは作者がChatGPTで制作したものです。アプリアイコンも作者がChatGPTで制作した原画に由来します。Coreのスクリーンショットには公開用の架空データを使用しています。
